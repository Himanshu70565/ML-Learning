# ML Daily Learnings

This repository contains my hands-on notebooks and small experiments while learning practical Machine Learning concepts, tools, and workflows.

## Repository Structure

- Binning/: Binning.ipynb - techniques for discretizing continuous features.
- Clustering/: Kmeans.ipynb - K-Means clustering experiments and visualization.
- Feature-Scaling/: Normalization.ipynb, Standardization.ipynb - scaling approaches and when to use them.
- Feature-Transformation-Encoding/: Encoding.ipynb - categorical encoding and feature transformations.
- HyperParameter-Tuning/: GridSearch_RandomizedSearchCV.ipynb — hyperparameter search examples using scikit-learn.
- Matplotlib-Library/: Matplotlib-Learning.ipynb — plotting and visualization examples.
- Numpy-Library/: Numpy-Learning.ipynb — core NumPy patterns and tricks.
- Outlier-Removal/: Outlier_Removal _Using_IQR.ipynb, Outlier_Removal_Using_Zscore.ipynb — IQR and Z-score based outlier removal.
- Pandas-Library/: Pandas-Learning.ipynb — everyday data wrangling with pandas.
- PCA/: PCA.ipynb — dimensionality reduction experiments with PCA.
- Pipelines/: With-Pipelines.ipynb, Without-Pipelines.ipynb — building and comparing scikit-learn pipelines.
- RandomForest/: Random_Forest_Classifier.ipynb — ensemble methods and model evaluation.
- Transformer/: Column_Transformer.ipynb, Function-Power-Transformer.ipynb — using transformers to prepare feature pipelines.
